CoffeeSoft — Usuarios

Administracion · Demos estaticos · Fase 1

Plantillas HTML estaticas del modulo de Usuarios del sistema CoffeeSoft ERP v2.0. Cada demo es autocontenido y funciona standalone. Los modales embebidos en la vista principal se activan al hacer clic en los botones de accion.

Vistas Principales

Tabla de Usuarios

Vista principal con sidebar, KPI cards, tabla con filtros y paginacion. Incluye modales embebidos de crear, editar, eliminar y ver.

usuarios.html →

Modales (Standalone)

Nuevo Usuario

Modal con formulario completo de 8 campos en grid 2 columnas. Incluye toggle de password y checkbox 2FA.

modal-nuevo-usuario.html →

Editar Usuario

Modal de edicion con datos pre-llenados. Avatar con iniciales, campos editables, y timestamp de ultima modificacion.

modal-editar-usuario.html →

Eliminar Usuario

Modal de confirmacion con icono de alerta, datos del usuario y advertencia de accion irreversible.

modal-eliminar-usuario.html →

Ver Usuario

Modal de solo lectura con avatar, badges de rol y estado, grid de datos organizado por secciones, y boton editar.

modal-ver-usuario.html →
